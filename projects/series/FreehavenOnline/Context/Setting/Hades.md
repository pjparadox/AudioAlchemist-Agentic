# Hades (The Underworld)

**Type:** Plane of Existence / High Level Zone.
**Location:** Haven Online (accessible via portals/death).

## Features
*   **Rivers:** Acheron, Cocytus, Phlegethon, Lethe, Styx.
*   **Rule:** Dangerous for living players. "Lost" players (digitization failures) are trapped here.
*   **Mechanic:** Setting bind point here makes a character "Lost" permanently without powerful magic.

## Significance
*   Setting for Book 3 (*LadyThunderlord Into Hades*).
*   Rescue mission location for Mirae and others.
