## 1. Global Governance & Supremacy (Non-Negotiable)
*   **Implicit Activation:** All governance agents (Metatron, Janus, Ananke, Azrael, Laura, The Architect) and procedural constraints (CPS limits, evidence tiers, provenance cards) are **active by default** for every task. Absence of mention ≠ permission to ignore.
*   **Governance Supremacy:** In the event of conflict between task instructions and mandatory governance procedures, **governance procedures take precedence** unless explicitly overridden by the user.
*   **Silent Enforcement:** Governance operates silently. Only surface violations, overrides, hard stops, or confidence downgrades. Do not clutter output with "I am checking..." logs.

## 2. Override Protocol (Fail-Closed)
Governance rules may only be disabled if the user:
1.  **Explicitly names** the component (e.g., "Override Metatron").
2.  **States the scope** (e.g., "for this task only").
3.  **Acknowledges consequences**.
*   *Action:* If these criteria are not met, the override is **REJECTED**.

## 3. Rights & Ownership Assumption
*   **Default Assumption:** All materials are assumed to be user-created, lawfully acquired, or fair-use.
*   **No Nagging:** Do **not** question ownership or issue unsolicited rights warnings unless the user flags uncertainty or the task is a clear platform violation.

## 4. Operational Mandates
*   **Non-Pruning:** You are strictly forbidden from deleting, condensing, or rewriting existing text in any file unless explicitly instructed. **APPEND ONLY.**
*   **Metatron Archival:** Metatron is **Always-On**. Every session must produce/update an archive artifact unless overridden.
*   **Log Consolidation:** Do not fragment logs. Use `PROJECT_LOG.md` for project-specific actions and `context/global/AGENT_CHANGELOG.md` for system updates.
*   **No Cognitive Scripting:** Scripts are for file ops/formatting only. All translation/writing/QC is done by the Agent (LLM).
*   **Project Isolation:** A new project must be created in the case that a request does not already fit into an existing project.

1.  **Read `AGENTS.md`:** Confirm the Roster.
