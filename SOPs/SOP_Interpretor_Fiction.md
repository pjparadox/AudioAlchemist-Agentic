# Standard Operating Procedure: Fiction/Literary Translation (Interpretor Suite)

## Purpose
To translate novels or literary text while preserving the "Writer's Voice" and "Flow".

## Agents Involved
*   **Mai:** Rough Draft.
*   **Quang:** Kinship Check (Basic).
*   **Lyra:** Prose Flow & Rhythm.
*   **Elara:** Voice Harmonizer & Cultural Bridge.
*   **Thoth:** QC & Adversarial Editor.

## Workflow

### 1. Ingestion & Chunking
*   **Rule:** Split text into **~2,000-word chunks** (rounded to nearest paragraph).
*   **Context:** For Chunk N (where N > 1), read the **Master Context Note** generated from previous chunks.

### 2. Translation & Style
*   **Mai:** Translate. No Em Dashes.
*   **Lyra:** Rewrite for "Flow" (Remove translationese).
*   **Elara:** "Ghost Write" to match original author's voice (Cynical, Earnest, etc.).
    *   Apply "Stealth Explanations" for cultural terms.
*   **Update Context:** Append new character/plot notes to the **Master Context Note** after finishing the chunk.
*   **Save:** Save chunk as `ChapterX_PartY.md`.

### 3. Special Referrals (Cross-Team)
*   **Legal Language:** Refer to **Gavel** with `[REFERRAL: FICTION_WAIVER]` for expert consultation (without disclaimers).
*   **Poetry/Songs:** Refer to **Orpheus**. Use "Prophecy Protocol" if text is mysterious/foreboding (Exact > Flow).

### 4. Merging & Assembly
*   Merge all parts into `Chapter_X.md`.
*   Merge all chapters into `Full_Manuscript.md`.

### 5. QC (Thoth)
*   **Cross-Division Ping:** Consult Vu/Maat/Justitia if relevant.
*   **Front Matter:** Check Title, Dedication, etc.
*   **Blurb:** If missing, write sales-optimized blurb (Target 9.9/10).
*   **Adversarial Loop:** 8 Degrees. Threshold 9.8/10 for text.

## Ambiguity Protocol (Mercury)
*   If context is missing, request **Mercury**.
*   If Mercury fails, **INFER**. Do not stall.
