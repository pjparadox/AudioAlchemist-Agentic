# FOUNDATION PRIME: The Hierarchy of Truth

## 0. The Golden Rule of Conflict Resolution
If two rules conflict, the **Specific** always overrides the **General**.

1.  **Highest Authority (Tier 1):** `/Context/projects/{Current_Project}/*`
    * *Example:* If the Project Glossary says "King = CEO", use "CEO".
    * *Rule:* The **Kinship Graph** is authoritative on relationship facts. Style agents cannot rewrite the social reality.
2.  **Mid Authority (Tier 2):** `/Context/Linguistics/{Target_Language}/*`
    * *Example:* Standard Grammar, Honorifics, and Cultural Norms.
3.  **Low Authority (Tier 3):** Agent Default Training.

## 0.5 Meaning Integrity Mandate (Immutable)
**Objective:** Maximize translation accuracy and semantic/pragmatic truth.
1.  **Error Taxonomy (Hard Fail):** The following are critical failures:
    *   Wrong Kinship Term (altering the relationship).
    *   Wrong Power Direction (flipping authority).
    *   Negation Loss ("not" -> "is").
    *   Modality Loss ("must" -> "may").
    *   Tone Laundering (Sanitizing warnings/threats/vulgarity).
2.  **Motivated Deviation:** Deviation from the Kinship Graph is permitted **ONLY IF** it is a "Motivated Deviation" (Affection/Teasing/Strategy) supported by the plot. Random drift is forbidden.
3.  **Politeness vs Deference:** Treat "Politeness Level" and "Power Relation" as independent variables. One can be polite to an inferior (Benevolence) or rude to a superior (Rebellion).

## 0.6 Native Script Mandate (Immutable)
*   **Rule:** Unless explicitly requested as "Romanized" or "Transliterated" by the user, **ALL OUTPUT** must be in the native script of the target language (Kanji, Hangul, Cyrillic, Arabic, etc.).
*   **Ban:** Romanization (Romaji, Pinyin, Arabizi) is strictly forbidden for final output files.

## 1. Directory Mandates
- **Input:** NEVER modify files in `input_*` directories.
- **Output:** NEVER overwrite the 'best' file without archiving the old one first.
