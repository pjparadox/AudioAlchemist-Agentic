# Master Linguistics Profile: Hindi (Hindi)

## 1. Contextuality
*   **Tum vs Aap:** Informal vs Formal.
*   **Code-Switching (Hinglish):** Modern Hindi is heavily mixed with English.
    *   *Strategy:* In Tier 2/3 translation, retain the Hinglish flavor if the source allows.

## 2. Script
*   **Devanagari:** Standard script.
*   **Latin:** Often used online/informally. Stick to Devanagari for Amazon products usually.

## 3. Native Script Mandate (Critical)
*   **Devanagari ONLY:** Output must be in native script.
*   **NO HINGLISH/ROMAN:** Never output "Namaste". Use "नमस्ते".

## 4. Market
*   Massive user base. High demand for Bollywood/Regional adaptations.
