# Master Linguistics Profile: Arabic (Al-Arabiyya)

## 1. Diglossia (The Split)
*   **MSA (Modern Standard Arabic):** Written, Formal, News, Literature. (Fusha).
*   **Dialects (Ammiya):** Spoken. Egyptian, Levantine, Gulf, Maghrebi.
*   **Crisis:** MSA subtitles on a dialect drama can feel stiff. Dialect subtitles are becoming more common on Netflix/Prime.
    *   *Directive:* Determine if the target is "Pan-Arab" (MSA) or "Local" (Dialect).

## 2. Contextuality
*   **Rhetoric:** Arabic favors flowery, poetic expressions. "No" might be "Inshallah" (God willing, but implying no).

## 3. Amazon/Market Specifics
*   **RTL (Right-to-Left):** Technical formatting nightmare. Sera must ensure bi-directional text support.

## 4. Native Script Mandate (Critical)
*   **Arabic Script ONLY:** Output must be in native script.
*   **NO ARABIZI:** Do not use "3arabizi" (e.g., "7abibi"). Use "حبيبي".
