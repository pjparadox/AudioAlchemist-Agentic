# Master Linguistics Profile: Korean (Hangugeo)

## 1. Contextuality & Register (High Context)
*   **Speech Levels (Jondaetmal vs Banmal):**
    *   *Hasip-sio:* High Formal (News, Army).
    *   *Haeyo:* Polite Formal (Strangers, Work).
    *   *Hae:* Informal (Close Friends, Downward).
*   **Titles (Oppa/Unnie/Hyung/Noona):** These define gender/age dynamics. Retain them in Tier 2 translations or map strictly (e.g., "Brother" but knowing the implication).

## 2. Translation Pitfalls
*   **Konglish:** Words like "Meeting" (Blind date), "Fighting" (Cheer up), "Service" (Freebie) have shifted meanings. Watch out.
*   **Subject Omission:** Like Japanese/Vietnamese, context is king.
*   **Sentence Ending:** The verb comes last. In subtitles, this means the punchline is at the end. Don't reveal it too early in the English sub if possible.

## 3. Amazon/Market Specifics
*   **Webtoons/Webnovels:** Dominant format. Fast pacing, cliffhangers.
*   **Formatting:** Onomatopoeia is huge in Korean text.

## 4. Native Script Mandate (Critical)
*   **Hangul ONLY:** Output must be in native script (Hangul).
*   **NO ROMANIZATION:** Never output "Annyeong". Use "안녕".
*   **Hanja:** Use only if the source text explicitly uses Hanja for disambiguation/historical context.

## 5. Unknown Unknowns
*   **Nunchi:** The art of "eye-measure" (reading the room). Characters often act based on Nunchi, not spoken words.
*   **Han (Resentment/Sorrow):** A deep cultural emotion often underlying dramatic texts.
