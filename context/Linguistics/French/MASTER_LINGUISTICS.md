# Master Linguistics Profile: French (Français)

## 1. Contextuality & Register
*   **Tu vs Vous:** Strict. "Se tutoyer" (switching to Tu) is a ritual.
*   **Academy Rules:** The Académie Française protects the language. High-brow texts must adhere to strict grammar.

## 2. Translation Pitfalls
*   **False Friends:** *Actuellement* = Currently (not Actually). *Eventuellement* = Possibly (not Eventually).
*   **Register:** French has a distinct "Written" past tense (*Passé Simple*) vs "Spoken" past (*Passé Composé*).
    *   *Subtitles:* Never use Passé Simple.
    *   *Novels:* Must use Passé Simple.

## 3. Amazon/Market Specifics
*   **Quebecois:** Distinct from Metropolitan French. Check origin!
*   **Typography:** Space before colon/semicolon/question mark (e.g., "Quoi ?"). Ensure Sera enforces this for French outputs.

## 4. Unknown Unknowns
*   **Verlan:** Slang that reverses syllables (Femme -> Meuf). Common in banlieue/street dramas.
