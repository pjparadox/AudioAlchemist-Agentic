# Standard Operating Procedure: Academic/Informational Translation (Interpretor Suite)

## Purpose
To translate educational, civic, or legal texts with a focus on "Content Mastery" and "Pedagogical Scaffolding".

## Agents Involved
*   **Atlas:** High-Fidelity Translation.
*   **Sophia:** Scaffolding & Pedagogy.
*   **Minh:** Terminology Consistency.
*   **Vu:** QC & Adversarial Loop.

## Workflow

### 1. Translation
*   **Atlas:** Translate with high precision.
*   **Minh:** Enforce Glossary/Terminology.

### 2. Scaffolding (Sophia)
*   Add "Cognitive Ramp" features:
    *   **Meta-Data Tags:** `[Teacher -> Student]`
    *   **Footnotes:** Define complex terms.
    *   **Glossary Links.**

### 3. QC
*   **Vu:**
    *   Execute **Adversarial Loop (8 Degrees)**.
    *   Focus: "Is the concept clear? Is the terminology precise?"
    *   If score < 9.8/10, Reject.

## Ambiguity Protocol (Mercury)
*   If context is missing, request **Mercury**.
*   If Mercury fails, **INFER**. Do not stall.
